CAMBIOS
La web se publica mediante GitHub Actions en:
https://jereprograma.github.io/E-MEDICAPP/
El backend Java y PostgreSQL permanecen en esta PC. Cloudflare proporciona un
túnel HTTPS saliente para que el cliente pueda acceder desde otro equipo.

Las rutas usan fragmentos (#/app/stock, por ejemplo), compatibles con actualización
directa en GitHub Pages. La conexión se puede establecer mediante el enlace
?api=... que genera AbrirDemoPages.cmd. El workflow también acepta la variable
pública VITE_API_BASE_URL, configurada para el túnel de esta presentación.

Se corrigió la pérdida de datos al regresar a la ventana: una sesión anónima se
conserva como resultado válido de consulta y una actualización en segundo plano
no desmonta el formulario de ingreso. El correo se conserva en la pestaña; la
contraseña escrita no se guarda en el almacenamiento del navegador.
Administración conserva también el formulario abierto ante un corte de conexión.

La sesión entre orígenes utiliza X-Auth-Session en sessionStorage, con CSRF,
rotación al ingresar, cierre e inactividad máxima de 30 minutos. Sólo se admite
el origen configurado de Pages. Documentos y logos privados se consultan con la
sesión autorizada. El acceso local incluido en el JAR conserva sus cookies.

USO POSTERIOR Y LÍMITES
AbrirDemoPages.cmd inicia el backend y el túnel, o reutiliza los procesos propios
ya iniciados, y abre el enlace completo para compartir.
DetenerDemoPages.cmd detiene esos procesos; conserva PostgreSQL y los datos.
La PC debe permanecer encendida y conectada. La URL temporal del túnel cambia al
reiniciarlo: compartir siempre el enlace nuevo que genera el acceso.

SMTP no está configurado. La demo funciona con sus cuentas precargadas; el alta
de cuentas nuevas queda pendiente de confirmación y la recuperación requiere
configurar correo para entregar enlaces reales. No se enviaron correos reales.
Pagos, facturas, recetas y cobertura se demuestran con comprobaciones y archivos
sintéticos. La guía de presentación está en docs/guion-demostracion.txt.
